예시 사이트(ourunit-cus.co.kr/hongje) 분석 및 핵심 동작 원리

🔍 예시 사이트 실제 코드 분석: "왜 웹에서 바로 단톡방 채팅을 쏘지 않고 클립보드 복사를 쓸까?" 핵심 기술 분석

카카오톡은 스팸 방지 및 보안 정책상 외부 웹사이트가 오픈채팅(단톡방)에 직접 메시지를 자동 전송(API Push)하거나 대화를 읽어오는 공식 API를 제공하지 않습니다.
따라서 예시 사이트(ourunit-cus.co.kr/hongje) 역시 실제 소스코드를 분석해보면, 손님이 장바구니에서 [공구방으로 이동] 버튼을 누를 때 navigator.clipboard.writeText("상품명 수량")으로 주문 내역을 클립보드에 자동 복사한 뒤 오픈채팅방을 열어 손님이 붙여넣기 전송하도록 구현되어 있습니다.

🔄 전체 서비스 핵심 동작 흐름도 (판매자 과일 등록 ➜ 고객 장바구니 주문 ➜ 자동 집계 & 오픈카톡 연동)
STEP 1 · 판매자
오늘의 과일 등록
관리자 웹에서 스마트폰으로 과일 사진·가격·한정수량(예: 30팩) 등록
➜
STEP 2 · 고객
닉네임 입력 & 장바구니
단톡방 링크 접속 → 오픈카톡 닉네임 입력 → 과일 종류·수량 담기 후 [전송하기]
➜
STEP 3 · 자동 집계 서버
DB 즉시 집계 & 알림
잔여수량 즉시 차감 · 품목별/닉네임별 자동 합산 · 사장님께 실시간 주문 알림
➜
STEP 4 · 오픈카톡방
단톡방 주문서 공유
주문 내역이 자동 복사된 상태로 단톡방이 열려 붙여넣기 전송 (공구 열기 UP)

오픈카톡 연동 및 자동 집계 아키텍처 2가지 방안 비교

지인분께서 24시간 켜두는 안드로이드 공기계(카톡 봇) 관리 부담 없이도 첫날부터 완벽하게 무료로 운영하실 수 있도록, 아래 두 가지 아키텍처를 비교하여 1단계(방안 A: 웹 직집계 하이브리드) 구축 후 필요시 2단계(방안 B: 카톡봇 파싱 추가)로 확장하는 전략을 제안합니다.

비교 항목 ★ 방안 A: 웹 즉시 DB 집계 + 오픈카톡 복사/이동 하이브리드 (강력 추천) 방안 B: 오픈카톡 공기계 봇 파싱 방식 (예시 사이트 원본 방식)
동작 원리 손님이 웹에서 [주문 전송하기] 클릭 시:
① 서버 DB에 즉시 주문 저장·자동 집계·재고 차감 완료
② 동시에 주문 텍스트 자동 복사 후 오픈카톡 단톡방 열기		 웹에서는 클립보드 복사 및 오픈카톡방 이동만 수행하고, 단톡방에 상주하는 안드로이드 공기계(메신저봇R 앱)가 채팅 알림을 읽어 서버로 전송
집계 정확도 및 재고 차감 누락 0% (100% 정확) · 버튼 클릭 즉시 한정수량(잔여 개수) 실시간 차감 및 품절 자동 처리 손님이 카톡방에 붙여넣기를 깜빡하거나 임의로 글자를 수정하면 파싱 오류·누락 발생 가능
사장님 실시간 알림 주문 즉시 관리자 웹 대시보드 실시간 갱신 + 사장님 텔레그램/카톡 알림 즉시 발송 공기계 봇이 채팅을 읽고 서버에 등록한 뒤 확인 가능
추가 장비/유지보수 추가 공기계 불필요 (100% 클라우드 무료 운영) · 배터리 방전이나 카톡 업데이트로 봇이 멈출 걱정 없음 24시간 충전기·와이파이에 연결된 안드로이드 공기계 1대 상시 구동 필수
단톡방 활성화 효과 손님이 카톡방으로 자동 이동해 복사된 주문서를 붙여넣으므로 단톡방 주문 인증 분위기 100% 동일 단톡방에 주문 채팅이 올라옴
📋 단톡방 자동 복사 주문서 포맷 & 사장님 공지 자동 생성 예시
💬 손님이 [전송하기] 클릭 시 클립보드 복사 양식 고객 단톡방 붙여넣기용

고객용 & 판매자(관리자)용 상세 기능 명세

🙋‍♀️ 고객용 모바일 웹 주요 기능 Customer Web
  • 오픈카톡 닉네임 자동 기억 (LocalStorage): 최초 1회만 입력하면 다음 접속 시 자동으로 내 닉네임과 내 예약 현황이 상단에 표시됨
  • 날짜별/특가별 탭 & 실시간 검색: 오늘의 과일, 내일 예약, 🎁 세트 특가, 매장 상시 구비 탭 분리 및 초성/이름 검색
  • 다중 사진 슬라이더 상세 모달: 과일 카드를 터치하면 실제 촬영한 여러 장의 과일 사진과 당도·산지 설명 확인
  • 실시간 재고 연동 장바구니: 남은 수량(예: 잔여 3팩)보다 많은 수량은 담을 수 없도록 제어하여 초과 주문 원천 방지
  • 원클릭 주문 전송 & 단톡방 이동: DB 저장 + 주문서 클립보드 자동 복사 + 오픈카톡 단톡방 실행을 버튼 하나로 처리
  • 입고 여부 실시간 배지: 내가 주문한 과일이 매장에 도착했는지(✅ 입고완료 / ❌ 미입고) 웹에서 즉시 확인
👨‍🌾 판매자(사장님) 관리자 페이지 주요 기능 Seller Admin
  • 스마트폰 30초 과일 업로드: 새벽 시장에서 휴대폰 카메라로 바로 찍어 올리면 브라우저에서 이미지를 자동 압축(WebP)하여 초고속 등록
  • 어제/기존 과일 원터치 재등록: 매일 반복 판매하는 과일(딸기, 사과, 바나나 등)은 기존 템플릿을 불러와 오늘 가격과 수량만 수정해 5초 만에 게시
  • 한정 수량 & 원터치 품절 토글: 준비한 박스 수량만 입력하면 주문 시마다 자동 차감되며, 오프라인 매장 판매분 발생 시 [+ / -] 버튼으로 재고 즉시 조정
  • 품목별 소분 요약표 & 닉네임별 장부 자동 생성: 오늘 총 몇 팩을 포장해야 하는지, 손님별로 얼마를 받아야 하는지 자동 합산
  • 단톡방 공지글 자동 생성기: [📢 오늘의 과일 공지 복사] 버튼을 누르면 오늘 올린 과일 목록+가격+주문링크가 이모지와 함께 깔끔하게 복사됨
  • 사장님 실시간 주문 알림 (무료): 신규 주문이 들어올 때마다 사장님 텔레그램/카카오톡으로 즉시 푸시 알림 전송

핵심 데이터베이스(DB) 스키마 설계

1️⃣ products (일별 판매 과일 테이블)
  • id (UUID, PK) / sale_date (판매·수령 날짜, 예: 2026-11-07)
  • name (과일명) / unit_label (판매 단위: 1팩, 1박스, 세트)
  • price (판매가) / description (당도·산지 코멘트)
  • images (과일 사진 URL 배열) / special_tab (특가 탭 구분)
  • is_limited (한정수량 여부) / remain_stock (실시간 잔여 수량)
  • is_received (매장 입고 완료 여부) / is_visible (노출 여부)
2️⃣ orders & order_items (주문 및 상세 품목 테이블)
  • orders.id (UUID) / order_date (주문일)
  • kakao_nickname (오픈카톡 닉네임 - 조회 및 그룹핑 기준 키)
  • total_amount (총 합계 금액) / status (예약중 · 수령완료 · 취소)
  • source (WEB 웹 직접 주문 / KAKAO_BOT 카톡봇 파싱 주문)
  • order_items: product_id, product_name, quantity(수량), unit_price(단가)
