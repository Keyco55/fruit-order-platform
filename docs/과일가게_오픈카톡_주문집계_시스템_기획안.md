# 과일 가게 모바일 웹 주문 및 오픈카톡 자동 집계 시스템 기획안

- **문서 버전**: v1.0
- **작성일**: 2026-11-07
- **벤치마킹 대상**: 우리동네국민상회 홍제점 (`https://ourunit-cus.co.kr/hongje`)
- **목표 환경**: 모바일 웹 (앱 설치 불필요, PWA 홈 화면 추가 지원)
- **배포 및 버전 관리**: GitHub + Vercel (Free Tier) + Supabase (Free Tier)

---

## 1. 프로젝트 배경 및 목표

### 1.1 도입 배경
동네 과일 가게에서 매일 새벽 경매·도매시장에서 입고되는 신선 과일을 카카오톡 오픈채팅방(단톡방)을 통해 선주문·예약 판매할 때 다음과 같은 운영상 고충이 발생합니다.

1. **수기 집계의 한계 및 누락 위험**: 단톡방에 수십~수백 건의 주문 채팅과 일반 대화("사과 달아요?", "오늘 몇 시까지 열어요?")가 섞여 올라오면 사장님이 일일이 눈으로 읽고 수기로 장부를 정리하다가 주문 누락이나 수량 착오가 발생합니다.
2. **실시간 재고(한정 수량) 관리 불가**: 오늘 준비한 딸기가 30팩뿐인데 단톡방 채팅만으로는 실시간 마감 처리가 어려워 초과 주문(오버부킹)이 발생합니다.
3. **고객의 주문 및 내 예약 확인 불편**: 고객 입장에서도 오늘 판매 중인 전체 과일 목록과 가격, 내 주문이 정상 접수되었는지, 매장에 상품이 입고 완료되었는지 한눈에 확인하기 어렵습니다.

### 1.2 핵심 목표
- **앱 설치 없는 3초 모바일 웹 주문**: 카카오톡 단톡방 공지 링크만 누르면 앱 설치나 복잡한 회원가입/로그인 없이 **오픈카톡 닉네임 입력만으로** 즉시 장바구니 담기 및 주문 가능
- **오픈카톡 단톡방 연동 + 100% 자동 집계**: 주문 전송 시 **서버 DB에 즉시 자동 집계**됨과 동시에 **오픈카톡 단톡방으로 주문 내역이 복사·공유**되어 단톡방의 활기(공동구매 분위기)와 정확한 데이터 집계를 동시에 달성
- **초기 구축비 및 월 서버 유지비 0원**: **GitHub + Vercel 무료 티어 + Supabase 무료 티어** 조합으로 소규모~중규모 동네 과일 가게 트래픽을 비용 부담 없이 안정적으로 운영
- **지속 가능한 개선 구조**: GitHub 저장소 기반 버전 관리 및 코드 푸시(`git push`) 시 Vercel을 통한 1분 내 무중단 자동 배포(CI/CD) 환경 구축

## 2. 예시 사이트(`ourunit-cus.co.kr/hongje`) 분석 및 오픈카톡 연동 원리

### 2.1 예시 사이트 실제 소스코드 분석 결과
참고하신 `https://ourunit-cus.co.kr/hongje` 사이트의 실제 웹 동작 코드를 분석한 핵심 구조는 다음과 같습니다.

1. **Toss 스타일 모바일 친화적 UI**: `Pretendard` 폰트와 높은 가독성의 카드형 레이아웃, 플로팅 장바구니 버튼(`🛒`), 상단 고정 날짜 탭 구조 채택
2. **닉네임 자동 기억 (`localStorage`)**: 고객이 한 번 오픈카톡 닉네임을 입력하면 브라우저 `localStorage`에 저장되어 재방문 시 다시 입력할 필요가 없음
3. **오픈카톡 전송 방식 (`goToKakaoFromCart`)**:
   - 카카오톡은 보안 및 스팸 방지 정책상 **외부 웹사이트에서 오픈채팅 단톡방으로 대화를 직접 자동 전송(API Push)하는 공식 API를 제공하지 않습니다.**
   - 따라서 예시 사이트는 고객이 `[공구방으로 이동]` 버튼을 누르면 **`"샤인머스켓 2\n딸기 1"` 형태의 주문 텍스트를 클립보드에 자동 복사**한 뒤, 안내 토스트 메시지(`"제품 내역 복사됐어요. 공구방에 붙여넣기 후 전송하시면 예약됩니다"`)를 띄우고 오픈채팅방 링크(`window.open`)를 실행합니다.

### 2.2 오픈카톡 연동 및 자동 집계 아키텍처 2가지 방안 비교

예시 사이트의 장점을 그대로 가져오면서, **안드로이드 공기계(카톡 봇) 관리 부담까지 없앤 개선된 하이브리드 방식(방안 A)**을 기본 아키텍처로 제안합니다.

| 비교 항목 | **방안 A: 웹 즉시 집계 + 오픈카톡 클립보드 연동 (강력 추천)** | **방안 B: 오픈카톡 공기계 봇 파싱 방식 (예시 사이트 방식)** |
| :--- | :--- | :--- |
| **동작 원리** | 고객이 웹에서 `[주문 전송하기]` 클릭 시 **① 웹 서버(DB)에 즉시 주문 저장·집계 및 재고 차감** + **② 클립보드에 주문서 자동 복사 후 오픈카톡방 열기** | 웹은 클립보드 복사 및 카톡방 이동만 수행하고, 단톡방에 상주하는 **안드로이드 공기계(메신저봇R)**가 채팅을 읽어 서버로 전송 |
| **집계 정확도** | **100% 정확** (고객이 웹에서 전송 버튼을 누른 시점에 이미 DB에 품목·수량·닉네임이 정확히 기록됨) | 고객이 카톡방에 붙여넣기를 깜빡하거나 오타를 내면 집계 누락 발생 가능 |
| **실시간 재고 차감** | **즉시 반영** (30개 한정 상품 주문 즉시 29개로 차감, 품절 자동 처리) | 카톡방에 붙여넣기 전까지 시차 발생 |
| **추가 장비 필요 여부** | **불필요 (완전 무료, 서버 100% 클라우드 동작)** | 24시간 전원과 와이파이가 연결된 **안드로이드 공기계 1대 필수** |
| **사장님(관리자) 알림** | 주문 즉시 관리자 웹 대시보드 실시간 갱신 + **텔레그램/카카오 알림 즉시 발송** | 공기계 봇이 파싱 후 서버에 반영될 때 확인 |
| **단톡방 홍보 효과** | 고객이 안내에 따라 카톡방에 붙여넣기 전송하므로 **단톡방 주문 인증 열기 동일하게 유지** | 단톡방에 주문 채팅이 올라옴 |

> **💡 핵심 제안 전략 (1단계 → 2단계 확장)**
> - **1단계 (기본 구축)**: 공기계 없이도 주문 누락이 0%인 **[방안 A: 웹 즉시 DB 집계 + 오픈카톡 복사/이동 하이브리드]** 방식으로 구축합니다.
> - **2단계 (선택 확장)**: 웹 링크에 들어오지 않고 단톡방에 직접 채팅(`"사과 2개요"`)만 치는 어르신 고객까지 자동 집계하고 싶을 때, 공기계(메신저봇R)를 추가해 웹훅 API(`/api/webhook/kakao`)로 연결할 수 있도록 서버 API를 열어둡니다.

## 3. 상세 기능 명세 (Feature Specifications)

### 3.1 고객용 모바일 웹 (`/`)
1. **상단 헤더 및 매장 공지사항 배너**
   - 가게 상호명, 영업시간/픽업 안내 공지 배너 표시
2. **내 예약/주문 내역 실시간 조회**
   - 오픈카톡 닉네임 입력창 (한 번 입력 시 기기에 자동 저장되어 다음 방문 시 자동 조회)
   - `[🎁 오늘 수령 예정]` 탭 / `[📦 전체 예약 상품]` 탭 구분
   - 주문한 과일별 **수량, 합계 금액, 입고 상태(`✅ 입고완료` / `⏳ 준비중`), 수령 상태(`수령완료`)** 실시간 표시
3. **날짜별·카테고리별 과일 목록 및 검색**
   - `[최근 등록 상품]`, `[오늘의 과일 (11/07)]`, `[내일 예약 상품]`, `[🎁 특가 세트]` 가로 스크롤 탭
   - 실시간 과일 이름 검색 필터
   - 상품 카드 구성:
     - 고화질 과일 썸네일 이미지 (클릭 시 다중 사진 슬라이더 및 당도·산지 상세 설명 팝업)
     - 과일명, 판매 단위(예: 1팩 / 1박스 / 3개 1세트), 판매 가격
     - 실시간 재고 배지: `구매가능`, `🔥 한정판매 (잔여 5팩)`, `품절 (Sold Out)`
     - `[바로 주문]` 버튼 및 `[+ 장바구니]` 담기 버튼
4. **플로팅 장바구니(`🛒`) 및 주문 전송 모달**
   - 우측 하단 플로팅 버튼에 담긴 과일 종류 수 배지 표시
   - 장바구니 모달에서 품목별 수량 증감(`-` / `+`), 총 예상 결제 금액 자동 합산
   - **오픈카톡 닉네임 확인 입력란** (필수) + 픽업 예정 시간/요청사항(선택)
   - **`[주문 전송 및 오픈카톡방 이동]` 버튼 클릭 시**:
     1. 서버 DB에 주문 내역 즉시 생성 및 잔여 수량 차감
     2. 사장님께 신규 주문 실시간 알림 발송
     3. 클립보드에 깔끔하게 포맷팅된 주문서 자동 복사:
        ```text
        [주문접수] 닉네임: 과일사랑
        - 설향 딸기(500g) x 2팩
        - 샤인머스켓(2수) x 1박스
        총 금액: 35,000원
        ```
     4. 오픈카톡 단톡방으로 자동 이동 (손님은 채팅창에 붙여넣기만 하면 끝)

### 3.2 판매자(관리자) 전용 페이지 (`/admin`)
> 사장님이 새벽 청과시장이나 매장에서 **스마트폰 하나로** 모든 작업을 1분 안에 끝낼 수 있도록 모바일 최적화 UI로 제작합니다.

1. **간편 관리자 인증**: 복잡한 아이디/이메일 없이 가게 전용 PIN 번호(또는 관리자 비밀번호)로 즉시 접속 (세션 유지)
2. **오늘의 과일 30초 등록/수정**
   - **스마트폰 카메라 즉시 촬영 또는 앨범 다중 사진 업로드** (클라이언트 자동 이미지 압축으로 용량 절약 및 초고속 업로드)
   - 과일명, 판매 날짜, 가격, 단위, 상세 코멘트(예: "오늘 경매 1등품! 당도 18브릭스 보장") 입력
   - **수량 제어**: 무제한 판매(`∞`) 또는 한정 수량(예: `30개`) 설정, 원터치 `[품절 처리]` / `[노출 숨김]` 토글
   - **자주 파는 과일 불러오기**: 어제/지난주 올렸던 과일 정보를 원터치로 복사해 가격과 수량만 바꿔 재등록하는 편의 기능
3. **실시간 자동 집계 대시보드 (핵심 기능)**
   - **① 품목별 총 주문 수량 요약표**:
     - 예: `설향 딸기: 총 42팩 (남은 재고 8팩)` / `샤인머스켓: 총 19박스 (품절)`
     - 시장 발주 및 매장 소분 포장에 즉시 활용
   - **② 고객(오픈카톡 닉네임)별 주문 카드 리스트**:
     - 닉네임 검색 및 초성/이름순 정렬
     - 각 고객의 주문 품목·총 결제 금액 확인
     - 원터치 상태 변경 버튼: `[입고완료 알림]`, `[결제확인]`, `[픽업(수령) 완료]`, `[주문 수정/취소]`
   - **③ 오픈카톡 공지용 텍스트 자동 생성 버튼**:
     - 오늘 등록한 과일 목록과 가격, 주문 웹 링크를 오픈카톡 공지에 바로 붙여넣을 수 있는 홍보 문구로 자동 생성·복사
   - **④ 엑셀(CSV) 다운로드**: 일별·기간별 매출 및 주문 내역 파일 다운로드

## 4. 시스템 아키텍처 및 기술 스택 (무료 티어 최적화)

### 4.1 기술 스택 선정 이유
앞으로 기능을 계속 개선하고 유지보수하기 가장 좋으면서, **초기 비용과 월 서버 비용이 0원**인 현대적 표준 스택입니다.

| 구분 | 채택 기술 | 선정 이유 및 무료 티어(Free Tier) 한도 |
| :--- | :--- | :--- |
| **프레임워크** | **Next.js 15 (App Router, TypeScript)** | 프론트엔드(고객/관리자 웹)와 백엔드 API(주문 접수, 집계, 웹훅)를 하나의 프로젝트로 통합 관리 가능 |
| **스타일링** | **Tailwind CSS + Pretendard 폰트** | 예시 사이트(`ourunit-cus.co.kr`)와 같은 깔끔한 토스(Toss) 스타일 모바일 UI를 빠르고 일관되게 구현 |
| **데이터베이스** | **Supabase (PostgreSQL)** | 무료 티어에서 500MB DB 제공 (텍스트 주문 데이터 기준 **약 50만 건 이상** 저장 가능), 실시간(Realtime) 주문 갱신 지원 |
| **이미지 저장소** | **Supabase Storage** | 무료 티어 1GB 제공. 과일 사진 업로드 시 브라우저에서 WebP(약 100~150KB)로 자동 압축하여 **약 7,000장 이상** 무료 저장 |
| **웹 호스팅 & 배포** | **Vercel (Hobby Free Tier)** | 월 100GB 대역폭 무료, HTTPS(SSL) 보안 인증서 자동 발급, GitHub 연동 시 무중단 자동 배포 |
| **버전 관리** | **GitHub** | 소스코드 이력 관리, 브랜치별 기능 테스트, 이슈 및 개선 내역 관리 |
| **관리자 알림** | **Telegram Bot API / 카카오 알림** | 신규 주문 발생 시 사장님 스마트폰으로 실시간 푸시 알림 (완전 무료) |

## 5. 데이터베이스(DB) 설계 (ERD 요약)

1. **`store_settings` (매장 기본 설정)**
   - `id`, `branch_code` (예: `main`), `store_name`, `notice_text` (공지사항), `kakao_openchat_url` (오픈카톡방 링크), `admin_pin_hash`, `show_price`, `show_stock`
2. **`products` (일별 판매 과일)**
   - `id` (UUID), `sale_date` (판매일/수령일), `name` (과일명), `unit_label` (단위: 1팩, 1박스 등), `price` (단가), `description` (상세 설명), `images` (이미지 URL 배열), `is_limited` (한정판매 여부), `total_stock` (총 준비 수량), `remain_stock` (잔여 수량), `is_received` (매장 입고 완료 여부), `is_visible` (노출 여부), `sort_order` (정렬 순서), `created_at`
3. **`orders` (고객 주문 마스터)**
   - `id` (UUID), `order_date` (주문일자), `kakao_nickname` (오픈카톡 닉네임), `customer_phone_last4` (동명이인 구분용 선택 입력), `total_amount` (총 주문 금액), `status` (`RESERVED` 예약접수 / `PICKED_UP` 수령완료 / `CANCELED` 취소), `source` (`WEB` 웹주문 / `KAKAO_BOT` 카톡봇집계), `memo` (요청사항), `created_at`
4. **`order_items` (주문 상세 품목)**
   - `id` (UUID), `order_id` (FK), `product_id` (FK), `product_name` (주문 시점 상품명), `unit_price` (주문 시점 단가), `quantity` (주문 수량), `subtotal` (합계)

## 6. GitHub 버전 관리 및 Vercel 자동 배포 파이프라인

앞으로 기능을 꾸준히 추가·개선하더라도 운영 중인 가게 사이트가 멈추지 않도록 **GitHub + Vercel CI/CD 파이프라인**을 구축합니다.

1. **로컬 개발 및 Git 브랜치 전략**
   - `main` 브랜치: 실제 고객과 사장님이 접속하는 **운영(Production) 버전**
   - `feat/*` 브랜치: 새로운 기능(예: `feat/stamp-coupon`, `feat/kakao-bot-webhook`)을 개발할 때 사용하는 작업 브랜치
2. **Vercel 자동 배포 흐름**
   - `feat/*` 브랜치를 GitHub에 `push`하고 Pull Request(PR)를 열면, Vercel이 **테스트 전용 임시 주소(Preview URL)**를 자동으로 만들어 줍니다.
   - 스마트폰으로 임시 주소에 접속해 새 기능을 테스트한 뒤 이상이 없으면 `main` 브랜치에 `merge`합니다.
   - `main`에 합쳐지는 즉시 **30~60초 이내에 실제 사이트에 무중단 배포**됩니다. (문제 발생 시 Vercel 대시보드에서 클릭 한 번으로 이전 버전 즉시 롤백 가능)

## 7. 단계별 구축 일정 및 향후 고도화 로드맵

### Phase 1: 핵심 MVP 구축 및 오픈 (약 1~2주)
- 프로젝트 초기 세팅 (Next.js + Tailwind CSS + Supabase 연동 + GitHub/Vercel 배포 연결)
- 판매자 관리자 페이지(`/admin`): 과일 사진/가격/수량 등록, 품절 토글, 품목별·닉네임별 자동 집계 대시보드
- 고객용 주문 페이지(`/`): 오늘의 과일 조회, 장바구니, 오픈카톡 닉네임 입력 및 주문 전송(DB 저장 + 클립보드 복사 + 단톡방 이동), 내 예약 조회
- 신규 주문 발생 시 관리자 실시간 알림 연동

### Phase 2: 운영 자동화 고도화 (운영 후 2~4주)
- **오픈카톡 공기계 봇(메신저봇R) 양방향 연동(선택)**: 단톡방에서 직접 텍스트로만 주문한 내역도 자동 파싱하여 웹 DB에 통합 집계 및 자동 답장("🍎 과일사랑님 설향딸기 2팩 예약 완료되었습니다!")
- **원클릭 재등록 및 세트 상품(묶음 할인) 기능**: 예시 사이트의 세트 묶음(`group_id`) 기능 지원
- **단골 장바구니 분석**: 날짜별/요일별 가장 잘 팔리는 과일 통계 및 적정 사입량 추천

### Phase 3: 단골 락인(Lock-in) 및 매출 확대
- **PWA(Progressive Web App) 적용**: 모바일 홈 화면에 가게 아이콘을 추가해 일반 앱처럼 전체 화면으로 실행 및 웹 푸시 알림 발송
- **오픈카톡 닉네임 기반 스탬프/적립금**: 10회 구매 시 과일 서비스 쿠폰 자동 안내
- **입금 확인 자동 매칭**: 계좌이체 입금 알림 문자를 파싱하여 주문 내역의 `[결제확인]` 상태 자동 체크
